🔐

نظام صلاحيات ثلاثي (RBAC)

مالك: لوحة تحليلات كاملة وإدارة المستخدمين. مدير: مهام إدارية. عامل: إدخال بيانات وطباعة فقط.

📱

تطبيق PWA — يعمل بلا إنترنت

Service Worker مع استراتيجية NetworkFirst للـ API وCacheFirst للأصول الثابتة. يحفظ البيانات محلياً ويزامن تلقائياً.

🖨️

طباعة إيصالات حرارية

مكوّن مُحسَّن لطابعات 58mm/80mm Bluetooth — أبيض وأسود، مع رمز QR لرقم الفاتورة.

📊

لوحة تحليلات مالية

إجمالي الإيرادات والمصروفات والربح الصافي (الإيراد − المصروفات)، مرشَّح حسب الشهر والمولدة.

⚡

توليد فواتير جماعي

زر واحد ينشئ فواتير شهر كامل لجميع المشتركين النشطين مع نقل الديون السابقة تلقائياً.

🌙

وضع ليلي كامل

Dark Mode مُخزَّن في localStorage — مثالي لجولات الجباية الليلية على الشاشات المضيئة.

🔍

بحث فوري للمشتركين

بحث بـ Debounce في اسم المشترك أو صاحب القاطع — يجد النتائج أثناء الكتابة.

💰

تنسيق العملة العراقية

جميع المبالغ بصيغة 150,000 د.ع باستخدام Intl.NumberFormat('ar-IQ').

🚀 تشغيل المشروع

خطوات إعداد بيئة التطوير المحلية

بيانات الدخول التجريبية

المالك:admin / كلمة المرور:admin123
العامل:worker1 / كلمة المرور:worker123 
# 1. استنساخ المستودع
git clone https://github.com/your-username/mawlidati.git
cd mawlidati

# 2. تثبيت الحزم
pnpm install

# 3. إعداد متغيرات البيئة
export DATABASE_URL=postgresql://user:pass@localhost:5432/mawlidati
export SESSION_SECRET=your-secret-key-here

# 4. رفع هيكل قاعدة البيانات
pnpm --filter @workspace/db run push

# 5. تشغيل الخادم
pnpm --filter @workspace/api-server run dev

# 6. تشغيل الواجهة (في terminal آخر)
pnpm --filter @workspace/mawlidati run dev
# إعادة توليد الـ API hooks من OpenAPI spec
pnpm --filter @workspace/api-spec run codegen

# فحص TypeScript لكل المشروع
pnpm run typecheck
